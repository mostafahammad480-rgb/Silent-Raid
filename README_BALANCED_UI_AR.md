# Silent Raid — Phone Balanced UI V2

هذه النسخة تضبط واجهة الهاتف مع الحفاظ على منطق اللعبة الأصلي.

- Full Screen أثناء اللعب.
- واجهة القائمة والـGame Over أصغر ومتوازنة.
- أزرار إعادة/الأدوار والـJoystick أكبر قليلًا.
- Zoom لعب خفيف 1.08x مع Clamp للكاميرا حتى لا يحدث قص مفاجئ للحواف.
- لا تغيير في منطق الخريطة أو الإضاءة أو الصوت.
