# V33 — Android

- تم استهداف اللص والحارس في الواجهة الرئيسية تحديدًا؛ وحجم V32 (30% فوق الحجم السابق) محفوظ بدون تكبير إضافي.
- زر «ابدأ المداهمة» يبقى مصغرًا 10% كما طلب المستخدم.
- تم تحسين السلاسة عبر تثبيت المحاكاة عند 60Hz وتقليل مرات الرسم الكاملة على الشاشات 90/120Hz.
- تم تقليل عمليات تدرج الإضاءة الثقيلة من عدة تمريرات إلى تمريرة واحدة أخف.
- تم تفعيل طبقة Hardware للـWebView وإجبار تحديث ملفات اللعبة المحلية.
